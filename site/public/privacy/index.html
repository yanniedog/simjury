Plain-language privacy

Your sitting stays with this browser.

SimJury has no player accounts or backend player-state service. Progress is useful because it is saved locally; that also means it cannot follow you to another browser or device.

01

What is stored

Your progress, notes, verdict, narration preferences and sitting statistics use this browser’s site storage on this device.

SimJury does not send that saved player state to an account or player-state backend.

02

No sync or recovery

There is no cross-device or cross-browser sync. Switching browser or device, using a separate browser profile, or clearing SimJury site data removes your access to the saved information there.

03

Optional narration

When narration is on, your browser can fetch public audio clips from GitHub Releases. GitHub can observe request metadata, request timing and the requested clip IDs.

Those requests do not contain your saved progress, notes, verdict or statistics. Clip IDs map to lines in SimJury’s public, pre-authored case corpus.

04

Web delivery, not player tracking

Static pages and assets are served through Cloudflare. Like any CDN, Cloudflare receives ordinary HTTP request metadata needed to deliver them.

SimJury does not add analytics or tracking code, and does not attach your locally saved progress, notes or verdicts to those requests.

05

Optional live jury rooms

If you host or join a private live jury, Cloudflare processes the display name you choose, your room seat, messages, stated position and optional reasons so invited participants can deliberate together.

The room also keeps capability-token hashes and creation, join and activity times. Live-room state is deleted when the room closes or expires after two hours. Anyone with the private invitation can join while seats remain, so do not post confidential information.

06

How the experience works

Daily cases are fictional and pre-authored. Authored juror responses and solo outcomes are produced deterministically in your browser from the case and your choices.

There is no runtime generative AI. Human contributions appear only in an optional room you deliberately host or join and are labelled as live participants.

Before you sit

Use the browser you want to return to.

If browser storage is unavailable, SimJury will still let you continue the current sitting and will warn you that it cannot resume later.
