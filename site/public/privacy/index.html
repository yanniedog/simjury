Plain-language privacy

Your Court Week record stays with your browser.

SimJury has no player accounts, analytics or backend player-state service. Progress is useful because it is saved locally; it reaches another browser or device only when you explicitly export and import it.

01

What is stored locally

Your session progress, current cue, accessibility and narration preferences, private notes, provisional ballot, final ballot and deliberation state use this browser’s IndexedDB on this device.

SimJury does not send that saved state to an account, GitHub, Cloudflare or another player.

02

Transfer and recovery

There is no automatic cross-device or cross-browser sync. You may explicitly export a versioned progress file and import it elsewhere. Private notes are included only when you select that option.

Clearing SimJury site data removes your local record unless you retained an export.

03

Audio and artwork

When media is used, your browser fetches reviewed public assets from the exact GitHub Release pinned by the case manifest. GitHub and its release-asset delivery service can observe normal request metadata, timing and opaque asset identifiers.

Those requests do not contain your saved progress, private notes, ballot or free-text reasoning.

04

Static delivery

Static pages, application code and small manifests are served through Cloudflare Static Assets. Like any CDN, Cloudflare receives ordinary HTTP request metadata needed to deliver them.

SimJury adds no analytics or tracking code and attaches no saved progress, notes or ballots to those requests. There is no SimJury Worker, D1 database, Durable Object or gameplay API.

05

Reviewed, local simulation

Eleven Minutes and every authored juror response are fictional and pre-authored. Outcomes are produced deterministically in your browser from the admitted record and your choices.

There is no runtime generative AI, multiplayer room, chat, email waitlist or account. Free-text notes are not interpreted by a server.

06

Retired services

The former Daily Docket live-room and email-waitlist services no longer accept data. Their Cloudflare bindings are removed from the active deployment.

Any retained waitlist export is handled by the operator outside GitHub under the documented quarantine and deletion process; it is never linked to Court Week play.

Before you sit

Use the browser you want to return to.

If persistent storage is unavailable, SimJury keeps the current session in memory and offers a local export rather than silently claiming it can resume later.
